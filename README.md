# 方块榜单

在 DeepSeek Harness 里创建、保存和查看自己的 A 股选股榜单。行情、条件计算和榜单管理都发生在插件内，打开就能用，不需要另外部署服务。

## 功能

- **自定义选股条件**：市场、行业、概念、地域、涨跌幅、成交额、量比、均线、涨停梯队、封板、热榜、估值，以及近 60 日涨跌停次数、最高连板、60 日涨跌幅、RSI、KDJ、BOLL、CCI 等指标。
- **现成模板**：今日涨停梯队、放量突破、热榜飙升、次新活跃、低位反转、60 日强势、炸板观察。
- **多种看法**：列表、卡片墙、排行榜、分组、芯片墙，可按行业、连板高度、涨跌幅区间或题材分组。
- **榜单管理**：最多保存 20 个榜单，支持新建、修改、删除、试算、分页和导出 CSV。
- **盘中预览**：盘中查看当前快照，正式榜单的数据日始终取最近一个完整收盘的交易日；盘中快照不写入历史。
- **对话操作**：不打开页面也能让模型创建、修改、删除和试算榜单。

## 安装

适用于 DeepSeek Harness `0.2.2-rc.5` 及兼容版本，使用 `web` 配置。

在 DSH 中依次打开：

1. **插件** → **实验性插件** → **自定义插件索引**，打开开关。
2. 进入 **发现**，点 **添加索引源**，填入：

   ```text
   https://sifan184.github.io/dsh-fangkuai-ranking/index.json
   ```

3. 在索引中找到 **方块榜单**，点 **安装**，确认来源后等待安装完成。
4. 重启 DSH（或按 DSH 提示重新加载），左侧栏会出现 **方块榜单** 入口。

## 首次使用

1. 打开 **方块榜单**，按设置页提示配置行情访问密钥。
2. 进入设置页，点 **初始化基础数据**。首次会回补近 6 个月日 K，约 5500 只股票，通常 1 分钟左右；进度条会显示当前处理数量，期间可以继续查看已有榜单。
3. 回到榜单墙，点 **添加榜单**，选一个模板或自己组合条件。编辑弹窗会自动试算并显示入选数量。
4. 保存后点榜单名称进入聚焦页，可分页查看完整名单，也可导出 CSV。
5. 在编辑弹窗的 **呈现方式** 中切换列表、卡片墙、排行榜、分组或芯片墙。

## 数据说明

- 使用免费公开行情，不需要另外购买数据服务。
- 正式榜单的 **数据日** 是最近一个已完整收盘的交易日，不是当前自然日。
- 盘中打开榜单会显示 `盘中预览 · HH:mm 快照 · 不入历史`，这份快照不会推进数据日，也不会写入榜单历史。
- 基础数据未初始化完成时，依赖 60 日历史数据的条件会提示缺少数据，不会把缺少数据误判成不符合。
- 本插件只做数据筛选和展示，不构成投资建议。
